# 🛒 Розумний кошик — програма для розрахунку вартості покупок

## 1. Опис проєкту

**«Розумний кошик»** — це консольний застосунок, створений мовою Python для автоматичного розрахунку вартості покупок.

Програма дозволяє додавати товари, вказувати їхню ціну та кількість, обчислювати загальну суму замовлення й автоматично застосовувати знижки. Наприкінці роботи користувач отримує підсумковий чек із результатами розрахунку.

## 2. Функціональні можливості

- Введення імені покупця.
- Додавання від 1 до 20 різних товарів.
- Введення назви, ціни та кількості товарів.
- Розрахунок вартості кожної позиції.
- Обчислення загальної суми покупки.
- Знижка 10% при сумі покупки від 1700 грн.
- Додаткова знижка 5% для власників VIP-картки.
- Вибір способу оплати.
- Перевірка правильності введених даних.
- Формування підсумкового чека.

## 5. Інструкція із запуску

1. Встановити Python версії 3.10 або новішої.
2. Завантажити або клонувати репозиторій.
3. Відкрити папку проєкту в терміналі.
4. Запустити програму командою:

```bash
python main.py
```

Для Windows також можна використати:

```bash
py main.py
```

Після запуску програма запропонує ввести дані покупця та інформацію про товари.

## 6. Приклад роботи програми

### Вхідні дані

```text
Введіть ім'я покупця: Андрій
Скільки різних товарів бажаєте придбати? 2

Товар №1
Назва товару: Навушники
Ціна за одиницю (грн): 1200
Кількість одиниць: 1

Товар №2
Назва товару: Мишка
Ціна за одиницю (грн): 600
Кількість одиниць: 1

Покупець має VIP-картку? (так/ні): так

Спосіб оплати:
1 — Готівка
2 — Банківська картка
3 — Онлайн-оплата
Ваш вибір (1/2/3): 2
```

### Результат виконання

```text
Покупець: Андрій

Навушники: 1200.00 грн × 1 = 1200.00 грн
Мишка: 600.00 грн × 1 = 600.00 грн

Категорія покупки: велика покупка
Сума до знижки:    1800.00 грн
Розмір знижки:     15%
Економія:          270.00 грн
До сплати:         1530.00 грн

Спосіб оплати:     Банківська картка

Знижку застосовано.
```

У прикладі покупець отримує загальну знижку 15%: 10% за суму покупки від 1700 грн та додаткові 5% за наявність VIP-картки.
